# Rights and attribution

## Historical source material

The original Intrade data, API manual, third-party JARs, and legacy project files are preserved with their provenance. No blanket license for these materials was present in the repository at the historical baseline commit. This modernization does not assert ownership of third-party material or retroactively assign it a new open-data license.

The generated research tables and contract downloads derive from those sources; conversion does not create a new grant of rights in the underlying data. Cite the archive and retain source attribution. Any dataset-wide reuse license for a preservation deposit must reflect rights actually held by the depositor.

## New tooling

The new Python/Java inspection and conversion tools, website source, tests and workflow code added in the modernization are provided under the MIT terms in `LICENSE`. That license is scoped to the new tooling and does not cover original source data, the historical API manual, bundled dependencies or legacy code.

## Citation versus permission

Citation metadata is provided separately in `CITATION.cff`. Attribution is not a substitute for permission where permission is required. Unknown historical terms are documented as unknown, not represented as public-domain status.
