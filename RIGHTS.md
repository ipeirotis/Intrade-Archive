# Rights and attribution

## Historical source material

The archive preserves the original Intrade data and API manual with their provenance. Reuse terms for this historical material are unspecified in the original repository. The original crawler and its bundled dependencies remain available in Git history and the v1.0.0 snapshot.

The generated research tables and contract downloads inherit the rights of their source material. Retain source attribution and use the recommended citations in the README. Dataset licensing for a preservation deposit must reflect the rights held by the depositor.

## Archive tooling

The Python/Java inspection and conversion tools, website source, tests, examples and workflow code added in the modernization are provided under the MIT terms in `LICENSE`. The license applies to the code in `scripts/`, `site/`, `tests/`, `examples/` and `.github/workflows/`.

## Attribution

The README provides the recommended paper citations. `CITATION.cff` records the archive metadata and associated references. Obtain any required reuse permission from the relevant rights holders.
