Read the data in context

Original files stay intact

Contract downloads contain byte-preserved source CSVs. Standardized tables include source file IDs and original record numbers for tracing observations.

Different sources remain distinct

Main-archive summaries and supplemental closing-price histories appear as separate chart series. The exports preserve source observations, including repeated records and gaps between dates.
